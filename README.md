# Visual Team · AI Agent Office

ออฟฟิศพิกเซลของทีมวิชวล GMS ตัวละครเดินไปห้องต่างๆ ตามแผน Daily Task ของแต่ละคน

- `index.html` — หน้าออฟฟิศ (ไฟล์เดียว)
- `data/status.json` — สถานะ/แผนวันนี้ของแต่ละคน (อัปเดตอัตโนมัติทุกเช้าวันทำงาน)
- `data/log.json` — บันทึก Daily Task 14 วันล่าสุด
- `data/config.json` — `formUrl` = ลิงก์ Microsoft Forms สำหรับข้อเสนอแนะ / ขอความช่วยเหลือ
